## Cocode

**Cocode 是一套开箱即用的 AI Agent 工作空间。** 它把文件、Git、终端、浏览器和 Agent 会话整合在同一个界面，同时提供桌面 GUI 和键盘优先的 TUI。

<a href="https://github.com/cocode-agency/cocode"><strong>浏览 Cocode 仓库 →</strong></a>

<br />

| 桌面工作空间 | 终端工作流 |
| --- | --- |
| 在一个界面中管理会话、文件、Git、终端、浏览器和代码差异 | 专为键盘操作和远程工作打造的专注客户端 |

## 我们的原则

- **实用胜过炫技。** 每个功能都应该帮助用户完成真实工作。
- **尽可能本地运行。** 工作空间、上下文和控制权应该留在用户身边。
- **默认可组合。** 小而透明的组件更容易构建可靠系统。
- **诚实说明边界。** 清楚区分本地、托管、实验性和已可用的能力。

## 从这里开始

如果你刚认识我们，可以从这里开始：
