# cocode-agency GitHub organization profile

This repository is the public organization profile for [`cocode-agency`](https://github.com/cocode-agency).

GitHub renders [`profile/README.md`](profile/README.md) on the organization Overview page. Keep the profile concise, factual, and useful to someone discovering the organization for the first time.

## Local preview

GitHub Markdown is the source of truth. To preview changes, open `profile/README.md` in GitHub or use any Markdown renderer that supports GitHub-flavored Markdown and relative images.

## Editing guidelines

- Keep links pointing to the canonical `cocode-agency` organization repositories.
- Describe project status conservatively; update it when the repositories change.
- Keep the profile free of secrets, private operational details, and credentials.
- Store reusable visual assets in `assets/` and reference them with relative paths.
